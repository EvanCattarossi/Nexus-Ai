# Workflow: Create App

## Purpose

Point d'entrée court pour démarrer un nouveau produit ou une nouvelle fonctionnalité majeure. Ce fichier redirige vers le workflow complet et documente uniquement le checklist de démarrage.

## Trigger

Une idée de produit ou de fonctionnalité majeure est prête à être évaluée par le CEO.

## Chain

Voir le cycle complet dans `agents/workflows/BUILD_APPLICATION.md` : Vision (CEO) → Étude & Budget (Business Analyst, Finance Analyst) → Specs & Design (Product Manager, UX/UI Designer) → Tech Design (Software Architect, Security Engineer) → Devs → Validation (QA, Security) → Déploiement (DevOps) → Lancement (Marketing, Content Creator).

## Checklist de démarrage

1. La proposition a-t-elle été soumise au `CEO.md` et a-t-elle reçu un Go (ou Go conditionnel) ?
2. Le `PROJECT_MANAGER.md` a-t-il été désigné comme coordinateur de bout en bout ?
3. Le dossier de besoin (`BUSINESS_ANALYST.md`) et l'avis de viabilité (`FINANCE_ANALYST.md`) sont-ils disponibles avant de passer aux spécifications produit ?

## Participating Agents

Identiques à `agents/workflows/BUILD_APPLICATION.md`.

## Notes

- Ce fichier existe pour un accès rapide au point de départ du cycle ; le détail complet des étapes vit dans `BUILD_APPLICATION.md` pour éviter la duplication et la divergence entre les deux documents.
