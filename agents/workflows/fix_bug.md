# Workflow: Fix Bug

Ce fichier est un alias court vers le workflow canonique **`agents/workflows/BUG_FIX.md`**.

Chaîne complète : Customer Support / Utilisateur → Project Manager (Triage & Priorité) → Software Architect (Attribution) → Dev concerné (Correctif) → QA Engineer (Validation) → DevOps Engineer (Hotfix Release).

Voir `BUG_FIX.md` pour le détail de chaque étape, les agents participants et les règles associées. Conservé sous ce nom pour compatibilité avec les références existantes ; toute évolution du workflow se fait dans `BUG_FIX.md` afin d'éviter la divergence entre les deux documents.
